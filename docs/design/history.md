# How the design items got here

The dated accounts behind the items of the documents in this directory that no decision record holds: what happened, in which issue or review, and what an item said before. Each document's items say what is true now, with their status and a reference, a decision's number or an issue's; the account that reference stands for is in the decision record where there is one, and otherwise here, under its document, opening with the item's section name.

Nothing loads this file, and no session reads it at its start (`docs/README.md`, rule 17). It is read when an item's reason is in doubt, or when an item is about to be changed, by a search for the item under its document's heading. An account is added here in the pull request that adds or changes the item, and is not rewritten afterwards.

## game.md

## battle.md

Resource nodes, the node with the least left. That a gathering ability works the node with the least left, so a gatherer fells one tree before starting the next, was the owner's call on Issue-15, on 2026-10-22.

The overrides. Forcing a unit's next action, and the party orders press on and retreat, were agreed on 2026-10-21 in Issue-110, and built in Issue-112.
