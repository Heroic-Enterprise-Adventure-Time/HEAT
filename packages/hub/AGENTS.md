# packages/hub

The GraphQL hub: Apollo Server on Lambda behind the HTTP API, a Pothos schema, DynamoDB and the replay bucket. The TypeScript standards of `packages/AGENTS.md` apply here too; these say how the schema, the resolvers and the data layer are written.

Read and follow the standards for this area: @../../docs/standards/graphql.md

The detail of that standard's rules, the whole of those it writes as one line, what it holds back and why, is `docs/standards/graphql-detail.md`, which nothing loads; its opening says when each section is read.
