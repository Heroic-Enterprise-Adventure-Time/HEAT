# packages/client

The Angular client: the browser game, served from each stack's bucket through CloudFront and run against a stack from the dev server. The TypeScript standards of `packages/AGENTS.md` apply here too; these say how the client itself is written.

Read and follow the standards for this area: @../../docs/standards/angular.md

The detail of that standard's rules, what it holds back and why, is `docs/standards/angular-detail.md`, which nothing loads; its opening says when each section is read.
